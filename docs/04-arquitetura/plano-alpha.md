# Primeiro bloco da Alpha

1. Configurar Angular e PO UI e validar o build com Node.js 24.
2. Exercitar regras do domínio com dados em memória e implementar o adaptador LocalStorage.
3. Implementar cadastros, navegação, detalhes e indicadores.
4. Validar o fluxo local, documentar as limitações e registrar o bloco no Git.

A interface consulta um serviço de aplicação. A persistência demonstrativa fica em um adaptador substituível. A API NestJS e o PostgreSQL são etapas posteriores.
