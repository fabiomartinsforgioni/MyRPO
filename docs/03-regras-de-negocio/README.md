# Regras de negócio

Todo chamado e projeto pertence a um cliente. Um chamado pode ser avulso ou vinculado a projeto do mesmo cliente. Chamados começam abertos e aceitam finalização direta, retorno da validação e reabertura. Arquivamento e pendência são independentes do status. Horas faturáveis consomem saldo contratado quando o controle de horas estiver disponível.

Consulte [Controle de horas](controle-de-horas.md) para as regras do cronômetro e dos relatórios demonstrativos.

O [catálogo técnico](catalogo-tecnico.md) documenta a base de conhecimento, as referências versionadas e as anotações por aba.
