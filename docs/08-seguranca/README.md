# Segurança

Use somente dados fictícios no navegador. O LocalStorage pertence ao perfil e à origem do navegador. Um ambiente compartilhado exige autenticação, autorização por workspace, auditoria e política para arquivos.

Consulte o [ADR 003](../adr/003-identidade-e-isolamento.md) para sessões, CSRF, gestão de vínculos, horas, anexos e critérios de segurança do piloto.
