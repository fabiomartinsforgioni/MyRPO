# Design

A identidade do MyRPO usa o logotipo em [Logo](../../Logo/MyRPO.png), navegação lateral recolhível e temas escuro e claro. Filtros, estados vazios e foco visível fazem parte das telas de cadastro.

Nos dois temas, a paleta azul diferencia navegação, ações e seleção. Os títulos usam a cor de texto do tema. O menu expandido usa o logotipo completo sobre fundo claro e o menu recolhido usa o mesmo [símbolo](../../Logo/MyRPO-icon.png) da aba do navegador.
